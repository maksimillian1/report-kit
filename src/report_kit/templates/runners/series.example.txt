#

# query is evaluated over the point's window and written to <run>.jsonl.
# Blank lines and # comments are ignored. A ref that returns no series fails
# the run with exit 2 — an empty result is a gap, not a zero. Where zero is
# genuinely the answer, write it: `... or vector(0)`.
#
# Confirm every query against the live endpoint before the first run, and
# date that confirmation in the execution's metric register. An unconfirmed
# ref cannot appear in a frozen Plan.
